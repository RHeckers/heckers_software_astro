## Situation

I worked at Marel from September 2019 to August 2023 as a full-stack engineer, on several products: a data visualisation framework, a warehouse management application, and the front-end applications around them. Those front-end applications were to be brought together in one Nx monorepo, and I was one of the leads on that migration.

## What I did

- Was one of the leads on the migration of all front-end applications to an Nx monorepo: the architecture, the module boundaries and the tooling.
- Introduced Nx Cloud and built new pipelines.
- Built the front end, the back end and the database of a data visualisation framework, with components such as charts, tables and gauges.
- Built a plugin system that loads Angular components into the data visualisation software at runtime.
- Built, with SignalR, an application in which customers monitor and control all operations in the warehouse.
- Implemented JWT login on the front end and the back end, single sign-on with OAuth, and the WCAG 2.1 standards in the component libraries.

## Result

The applications became more stable, and build, test and lint times dropped, locally and in CI. With Nx Cloud more pull requests run in parallel, compute costs went down, and errors in CI show up sooner.
