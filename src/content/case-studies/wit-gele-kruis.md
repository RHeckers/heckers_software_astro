## Situation

More than 40 front-end developers at Wit-Gele Kruis build on one shared front-end platform: a desktop application with Angular and Nx, and mobile applications with Capacitor, Electron, Node.js and SQLite. The teams' velocity was low, the component library was not accessible, and data used offline had to meet the security requirements. I joined in January 2025 as lead of the front-end platform team, the team that builds the shared code for all the others.

## What I did

- Designed Nx generators, simplified the component APIs and wrote abstractions for NgRx and Angular.
- Wrote scripts that cut the Cypress run from 90 minutes to 10.
- Implemented the WCAG 2.1 standards in the component library.
- Built the complex components (charts, pivot tables, matrix grids) and made them available through simple APIs.
- Implemented encryption for SQLite, so offline use is safe.
- Improved the CI/CD pipelines with custom lint rules and SonarQube rules, wrote the Storybook documentation, and raised the coverage of the Cypress end-to-end and component tests.

## Result

Productivity rose by 20%. A full Cypress run takes 10 minutes instead of 90. More than 40 front-end developers build accessible applications from the same component library, and offline data meets the security requirements.
